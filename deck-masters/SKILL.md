# deck-masters

HTML 幻灯片母版 skill。用于把内容先套成套版表，再按母版生成单个 HTML 文件。适合 16:9（1920×1080）产品界面风 PPT，设计语言借鉴 ian-xhs-carousel 的锌灰中性色、分层底盘、卡片阴影与点缀色纪律。

## 0. 这套 skill 的工作方式

- 先用一句话说清：**听众要带走什么**
- 再出：**套版表**
- 用户确认后：**按母版生成单个 HTML**
- 版位字数写死：**超限改文案，不缩字号**
- 一次只做一套 deck，不混多套视觉规则

## 1. 输入清单

生成前先收齐这些信息：

- 内容 / 大纲
- 主题
- 点缀色
- 演讲者信息
- 页数意向（一般 8–12 页，克制）

## 2. 固定层与自由层

### 2.1 两层规则

- **固定层**：画布、字号档位、颜色层级、底盘、卡片样式、点缀色纪律
- **自由层**：每页的版式选择与内容编排

固定层永远不动；自由层只在版式与内容组织里变化。

### 2.2 底盘规则

内容页（要点 / 数据 / 图表 / 对比 / 团队）在标题组下方铺一块浅灰底盘：

- 圆角大卡片
- 细边
- 分层阴影
- 内容卡片都放在底盘上
- 像从真软件里截出来的

限制：

- 封面、观点、章节、结尾页不用底盘
- 一页只放一块底盘

### 2.3 颜色层级

浅色主题固定值：

- 页面：`#fafafa`
- 底盘：`#efeff1`
- 卡片：`#ffffff`
- 卡内浅灰块：`#f4f4f5`

文字五级：

- `#18181b`
- `#3f3f46`
- `#52525b`
- `#71717a`
- `#a1a1aa`

深色主题对应值：

- 页面：`#101014`
- 底盘：`#17171c`
- 卡片：`#1d1d24`
- 文字五级反转

说明：

- 深色主题只影响整套对应值
- **章节页恒深色**，不随主题变

### 2.4 点缀色纪律

默认点缀色：`#3d8bff`

规则：

- **一页只用一处点缀色**
- 点缀色留给这页最想让人看的元素：
  - 关键数字
  - 推荐栏
  - 结论条
  - 当前章节序号
- 页码、目录序号小点不计入点缀色
- 绿色只表示“对 / 上涨 / 完成”，不当装饰色

### 2.5 字号档位

只允许使用下列字号档位。写成表，禁止自定义临时字号。

| 类名 | 字重 | 字号 / 行高 | 用途 |
|---|---:|---:|---|
| display | 600 | 120 / 132 | 封面主标题、观点主句 |
| title | 600 | 64 / 76 | 页标题 |
| heading | 500 | 44 / 56 | 卡片小标题、栏标题 |
| body | 400 | 38 / 56 | 正文 |
| strong | 500 | 38 / 56 | 条目标题 |
| caption | 400 | 30 / 44 | 说明、小注 |
| label | 500 | 26 / 36 | 标签 |
| num | 600 | 26 / 36 | 数字专用字体感，序号计数 |
| metric | 600 | 150 / 160 | 大数字 |
| code | 400 | 26 / 40 | 代码 / 参数 |

补充：

- 数字与英文用同一字体栈，但字重拉开
- 一页只放一个 display 或 title 级标题

### 2.6 卡片规则

- 2px 浅描边
- 圆角 28
- 分层阴影
- 对话框 / 主卡阴影更深，浮在底盘上

## 3. 版式清单（S01–S11）

### 3.1 开场

#### S01 cover 封面

用途：

- 开场定调
- 只讲一个主命题

版位规格：

- 主标题：`display`，≤2 行，每行 ≤12 字
- 副标题：1 行，≤24 字，`body`
- 底部信息行：演讲者 / 场合 / 日期，`caption`

限制：

- 不用底盘
- 不放多余模块

#### S02 toc 目录

用途：

- 给出整场结构
- 让听众先知道路线

版位规格：

- 页标题：`title`
- 条目 3–6 条
- 每条：序号 + 标题 ≤10 字 + 可选注 ≤18 字

限制：

- 目录要短
- 不写成大纲堆砌

#### S03 section 章节页

用途：

- 节奏点
- 章节切换

版位规格：

- 恒深色
- 点缀色巨号序号：`metric`
- 章节标题：≤10 字，`display`
- 导语：≤24 字，`body`

限制：

- 全 deck 的节奏点
- 不随主题变色

### 3.2 论述

#### S04 statement 观点页

用途：

- 先抛结论
- 适合一句话立论

版位规格：

- 主句：≤2 行，每行 ≤12 字，`display`
- 小注：≤28 字，`body`

限制：

- 不用底盘
- 不堆列表

#### S05 bullets 要点页

用途：

- 结构化陈述
- 适合拆 3–5 点

版位规格：

- 页标题：`title`
- 要点 3–5 条
- 每条：条标题 ≤10 字，`strong`
- 条说明 ≤30 字，`body`
- 内容进底盘卡片

限制：

- 一页只放一块底盘
- 不超 5 条

#### S06 compare 对比页

用途：

- 两方案 / 两阶段 / 两路径对照

版位规格：

- 双栏
- 栏标题 ≤8 字
- 每栏要点各 ≤4 条
- 每条 ≤14 字
- 底部结论条 ≤30 字
- 推荐栏可点缀色描边

限制：

- 推荐栏描边算本页那一处点缀色
- 不再额外加别的点缀色

### 3.3 数据

#### S07 data 数据页

用途：

- 展示关键指标
- 让数字先说话

版位规格：

- 大数字 1–3 个
- 数字 ≤6 字符，`metric`
- 标签 ≤8 字，`label`
- 涨跌注 ≤10 字
- 涨跌用绿色 / 红色语义色

限制：

- 不把数字塞太多
- 数据必须可追溯

#### S08 chart 图表页

用途：

- 用图说明趋势 / 构成 / 对比

版位规格：

- 页标题：`title`
- 图表区：柱状 / 折线
- 内联 SVG 按 DATA 生成
- 数据点 ≤8
- 带数值标注
- 结论条 ≤30 字

限制：

- 禁外部库
- 图表标注与数据一致
- 数据点别过多

### 3.4 展示

#### S09 split 图文页

用途：

- 左右分栏展示图与文
- 适合产品截图、流程图、示意图

版位规格：

- 图区一侧约 45%
- 用户图或占位框
- 标题 ≤12 字
- 正文 ≤4 行，每行 ≤22 字

限制：

- 图与文比例稳定
- 不让文字压过图

#### S10 team 团队页

用途：

- 展示成员与分工

版位规格：

- 成员 2–4 人
- 头像占位圆
- 姓名 ≤5 字
- 头衔 ≤10 字
- 介绍 ≤18 字

限制：

- 头像只做占位
- 信息短、整齐、克制

### 3.5 收尾

#### S11 ending 结尾页

用途：

- 结束收束
- 留下最后一句话

版位规格：

- 主句：≤12 字，`title`
- 副行：≤24 字
- 联系行：`caption`

限制：

- 不用底盘
- 只留收束信息

## 4. 套版表

生成前必须先给套版表，再等用户确认。

### 4.1 套版表头写法

先写三行头：

- 这套 deck 想让人带走什么
- 主题
- 点缀色

### 4.2 套版表字段

表格列固定为：

| 页序 | 这页讲什么 | 版式 | 图上标题 | 版位文案要点 |
|---|---|---|---|---|

要求：

- 先把每页的作用说清楚
- 再选版式
- 再写图上标题
- 再写版位文案要点

### 4.3 套版表下注

表下注明：

- **删掉了什么内容**

### 4.4 4 页小示例

示例主题：虚构产品发布

这套 deck 想让人带走什么：新产品为什么现在值得上手  
主题：light 浅色  
点缀色：`#3d8bff`

| 页序 | 这页讲什么 | 版式 | 图上标题 | 版位文案要点 |
|---|---|---|---|---|
| 1 | 开场定调，先抛一句总判断 | S01 cover | 让 AI 真正进入日常工作 | 主标题两行；副标题交代产品定位；底部写演讲者与日期 |
| 2 | 用三条讲清核心变化 | S05 bullets | 三个变化，改变使用方式 | 3 条：更快、更准、更可控；每条一句说明 |
| 3 | 用数据证明效果 | S07 data | 试用转化提升 | 2 个大数字：转化率、留存率；配涨跌注（均为示例数据） |
| 4 | 收束并给出下一步 | S11 ending | 现在就开始试用 | 主句收束；副行给出试用入口；联系行放二维码说明 |

删掉了什么内容：

- 删除产品史
- 删除冗长背景
- 删除无关功能清单
- 删除过多参数解释
- 删除重复结论

## 5. 工作流程

### 5.1 标准流程

1. 消化内容
2. 套版表
3. 等确认
4. 填母版出图
5. 自查
6. 交付

### 5.2 停顿规则

- 中间只停一次：停在“套版表 → 等确认”
- 确认后直接生成，不再二次改版式
- 若内容变动，重新回到套版表

## 6. 出图规范

### 6.1 文件与结构

- 单个 HTML
- 顶部固定：

```js
const DATA = { theme, accent, presenter, pages: [...] }
```

- 每页使用：

```html
<section class="slide">
```

- 画布尺寸：`1920×1080`
- 预览需等比缩放适配窗口

### 6.2 打印与导出

- 打印样式：

```css
@page { size: 1920px 1080px; margin: 0 }
```

### 6.3 图表

- 图表内联 SVG 生成
- 禁外部库
- 数据点 ≤8
- 标注必须与数据一致

### 6.4 字数与超限处理

- 版位字数超限时：
  - `console.warn`
  - 红虚线框提示
- 超限改文案，不缩字号

### 6.5 依赖限制

- 零外部依赖
- 字体用系统栈
- 不引 Web 字体
- 不发外部请求

### 6.6 缩放要求

- 预览缩放不变形
- 画面比例始终保持 16:9

## 7. 生成要求

生成 HTML 时必须满足：

- 只输出一个 HTML 文件
- 结构清晰
- 每页按指定版式落位
- 颜色层级与点缀色纪律严格执行
- 字号只用档位表
- 内容页才有底盘
- 章节页恒深色
- 图表数据真实一致
- 页码齐全
- 无外部请求
- 缩放不变形

## 8. 自查清单

交付前逐项检查：

- [ ] 字数不超限
- [ ] 字号只用了档位表
- [ ] 每页点缀色只有一处
- [ ] 底盘只出现在内容页且一页一块
- [ ] 章节页为深色
- [ ] 图表标注与数据一致
- [ ] 数据不编造
- [ ] 页码齐全
- [ ] 无外部请求
- [ ] 缩放不变形

## 9. 交互约束

- 先问清内容，再给套版表
- 用户确认前，不直接生成最终 HTML
- 套版表要可执行，不写空话
- 生成时严格按母版落版
- 不擅自扩展版式系统
- 不引入额外视觉风格

## 10. 输出风格

- 中文
- 务实
- 无营销腔
- 章节编号清楚
- 规格表格明确
- 复选框可用于验收
- 适合直接作为 skill 的说明文档

## 11. 最小使用方式

当用户说：

- “用母版做个 PPT”
- “给我一套幻灯片母版”
- “套 deck-masters 出个 deck”

应先返回：

1. 这套 deck 想让人带走什么
2. 主题
3. 点缀色
4. 套版表

然后等待确认，再继续生成单个 HTML deck。
